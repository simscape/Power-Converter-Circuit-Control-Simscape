Description

The Non-Isolated DC-DC Controller block regulates the output voltage of the Non-Isolated DC-DC plant. An outer voltage loop produces a current reference, an inner current loop produces a duty cycle, and the modulator turns that duty cycle into gate signals. A soft-start ramp brings the reference up over softStartTime.

Set modelOption to the same topology as the plant. It selects the duty law and, for the three synchronous topologies, adds the complementary gate for the synchronous rectifier.

Model Options

modelOption - Topology

Selects the duty law that converts the current-loop output into a duty cycle, and whether a second gate is produced. Six values: Buck, Synchronous Buck, Boost, Synchronous Boost, Buck-Boost and Synchronous Buck-Boost.

loopStructure - Control structure

OptionEffect
Single loopThe voltage PI produces the duty cycle directly. The Current Controller parameters and the current reference limits have no effect.
Double loopThe voltage PI produces a current reference, limited to iRefMinPu to iRefMaxPu, and the current PI produces the duty cycle.

cntrlSelect - Controller type

OptionEffect
PI controller (Continuous)Continuous-time PI blocks. The modulator uses the variable-step carrier.
PI controller (Discrete)Discrete-time PI blocks. The loop sample time parameters become visible, and the modulator uses the fixed-step carrier.

outputSelect - Output signal

OptionEffect
PWM SignalThe block carries the modulator and outputs gate signals at the gate voltage levels. Fsw, Tdead and the gate voltages apply.
Duty CycleThe block outputs the duty cycle. Supply your own modulator, for example a Half Bridge PWM Generator block.
