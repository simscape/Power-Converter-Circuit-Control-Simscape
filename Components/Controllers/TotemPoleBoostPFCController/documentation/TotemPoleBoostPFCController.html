Description

The Totem-Pole Boost PFC Controller block regulates the DC bus of the Totem-Pole Boost PFC plant and shapes the line current. The cascade is the one the Boost PFC Controller uses. What differs is the output: this block drives two legs, a fast leg at Fsw and a slow leg that commutates with the line voltage polarity.

The fast leg pair is separated by fastLegDeadTime. The slow leg device turns on slowLegTurnOnDelay after the line voltage crosses zero, which keeps the two slow leg devices apart across the crossing.

Ports

Input

PortSizeDescription
Vref1DC bus voltage reference, in volts.
Vmeas1Measured DC bus voltage, in volts.
Imeas1Measured boost inductor current, in amperes.
Vac1Measured AC input voltage, in volts. Sets the current reference shape and the slow leg polarity.

Output

PortSizeDescription
G4Gate vector for both legs.

Gate Vector Order

ElementDrivesRole
1Fast leg high-side deviceSwitching frequency.
2Fast leg low-side deviceSwitching frequency.
3Slow leg high-side deviceLine frequency. On for the half cycle that needs it.
4Slow leg low-side deviceLine frequency. On for the other half cycle.
Note: G is four elements wide, which matches the plant input whichever slow leg device the plant uses. With a diode slow leg the plant terminates elements 3 and 4, so the same connection serves all three slow leg choices.

Model Options

outputSelect - Output mode

OptionEffect
PWM SignalThe block carries both modulators and outputs the four-element gate vector at the gate voltage levels.
Duty CycleNot supported in this release. Selecting it stops the model from updating, so use PWM Signal.

cntrlSelect - Controller type

OptionEffect
PI controller (Continuous)Continuous-time PI blocks. The modulator uses the variable-step carrier.
PI controller (Discrete)Discrete-time PI blocks. The modulator uses the fixed-step carrier.
