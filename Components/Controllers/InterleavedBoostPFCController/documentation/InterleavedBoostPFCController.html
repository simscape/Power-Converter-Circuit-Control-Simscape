Interleaved Boost PFC Controller

Average current mode control with current balancing for a two-phase boost PFC stage

Description

The Interleaved Boost PFC Controller block regulates the DC bus of the Interleaved Boost PFC plant and shapes the line current. It adds a current balance loop to the cascade used by the Boost PFC Controller: the two phase currents are compared, and a duty trim limited to dutyBalanceMax is added to one leg and subtracted from the other.

The two carriers are separated by half a switching period, so the two inductor current ripples partly cancel in the line current.

Ports

Input

PortSizeDescription
Vref1DC bus voltage reference, in volts.
Vmeas1Measured DC bus voltage, in volts.
IL11Measured phase 1 inductor current, in amperes.
IL21Measured phase 2 inductor current, in amperes.
Vac1Measured AC input voltage, in volts. Sets the current reference shape.

Output

PortSizeDescription
G2Gate signals for the two boost switches, or the two duty cycles. Two elements in both output modes.

Gate Vector Order

ElementDrivesRole
1Phase 1 switch Q1Carrier at 0 degrees.
2Phase 2 switch Q2Carrier at 180 degrees.
Note: The order matches the plant input G, whose element 1 drives the phase 1 switch. Swapping the two elements does not stop the converter, because the balance loop then corrects the wrong leg, so check the order before you trust a balance result.

Model Options

outputSelect - Output

OptionEffect
PWM SignalThe block carries the two interleaved modulators and outputs gate signals at the gate voltage levels. Fsw, numberOfLegs and the gate voltages apply.
Duty CycleThe block outputs one duty cycle per leg, each limited to dutyMin to dutyMax. Supply your own modulators, and phase their carriers yourself.

cntrlSelect - Controller type

OptionEffect
PI controller (Continuous)Continuous-time PI blocks. The modulator uses the variable-step carrier.
PI controller (Discrete)Discrete-time PI blocks. The loop sample time parameters become visible, and the modulator uses the fixed-step carrier.
