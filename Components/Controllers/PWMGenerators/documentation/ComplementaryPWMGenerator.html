Complementary PWM Generator

Complementary gate pair with dead time, from an existing PWM signal

Description

The Complementary PWM Generator block splits one PWM signal into the two gate signals of a leg. The input is compared with inputLogicThreshold, and each gate is held off for Tdead after the other one turns off.

Turn-off follows the input edge with no delay and only turn-on is delayed, so the two gates never overlap. A pulse shorter than Tdead produces no gate.

Ports

Input

PortSizeDescription
PWM1PWM signal. Any amplitude, compared with inputLogicThreshold.

Output

PortSizeDescription
G2Gate vector for the two devices of the leg.

Gate Vector Order

ElementDrivesRole
1High-side deviceOn while the input is above the threshold.
2Low-side deviceOn while the input is below the threshold.
Note: The output is a gate voltage, not a logic level. Set gateVoltageOn and gateVoltageOff to straddle the gate threshold of the device you drive, and drive a Simscape™ gate through a controlled voltage source.

Model Options

solverMode - Solver mode

OptionEffect
Variable-step (continuous)The internal timer is an integrator. Use it with a continuous or a variable-step solver.
Fixed-step (discrete)The internal timer is a discrete counter running at Ts. Use it with a fixed-step solver, or to keep the gate edges on a known grid.
