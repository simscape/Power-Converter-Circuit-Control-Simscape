Single phase shift constant-current and constant-voltage control

Description

The DAB Controller (SPS) block controls the DAB Converter plant by single phase shift modulation. One PI loop produces the phase shift between the two bridges, limited to phaseShiftMin to phaseShiftMax. The modulator turns that phase shift into two four-element gate vectors.

The CCCV input selects which quantity the loop regulates, so the same block serves a constant-current stage and a constant-voltage stage. Both bridges switch at Fsw with a fixed half-period pulse width.

PortSizeDescription

Output Width

outputSelectWidthContents
Gate Signals4 and 4Gate vectors at the primary and secondary gate voltage levels. Connect them to the plant inputs Gp and Gs.
Phase Shift (rad)1 and 1Both ports carry the commanded phase shift in radians. Drive a DAB PWM Generator block with it.

Gate Vector Order

Both vectors use the same element order.

ElementDrivesRole
1Leg A high-side deviceFirst diagonal.
2Leg A low-side deviceSecond diagonal.
3Leg B high-side deviceSecond diagonal.
4Leg B low-side deviceFirst diagonal.
Note: Elements 1 and 4 form one conducting diagonal and elements 2 and 3 the other. Elements 1 and 2 are the two devices of one leg, so they are never on together.

OptionEffect
