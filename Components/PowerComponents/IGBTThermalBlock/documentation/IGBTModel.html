Description

The IGBT Model block models an ideal switching IGBT with a thermal port. Conduction loss, switching loss and anti-parallel diode loss are evaluated in Simulink. The total loss is injected as heat into a junction thermal mass. The junction connects through the junction to case thermal resistance to port A, and the junction temperature feeds back into the loss tables.

The gate is a physical port. Drive it with a controlled voltage source, or with the gate voltage levels a PWM generator block produces, and set the gate-emitter threshold to a value between the OFF and ON levels.

Note: Port A is a thermal conserving port. Connect it to a Thermal Reference block, a Temperature Source block or a thermal network. The junction temperature is computed inside the block and is not exposed as a port.

Model Options

Anti-parallel diode

OptionEffect
Inbuilt diodeThe block carries the anti-parallel diode. Its forward characteristic and its loss table are set on this dialog and its loss heats the IGBT junction.
External diodeThe block carries no diode. Connect a separate diode across C and E, and its loss is counted in that device.
