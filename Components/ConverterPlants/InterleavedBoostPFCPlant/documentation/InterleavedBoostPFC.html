Description

The Interleaved Boost PFC block models a single-phase power factor correction power stage with two boost phases sharing one rectifier and one output capacitor. A two-element gate vector drives the two boost switches.

The circuit contains:

  • Diode rectifier bridge - four diodes, D1 to D4.
  • Boost phase 1 - L1, switch Q1, boost diode Db1.
  • Boost phase 2 - L2, switch Q2, boost diode Db2.
  • Pre-charge branch - the resistor Rpc in series with a diode, bridging the rectified node to the output.
  • Output filter - the capacitor Co with its series resistance.

Export to Unmasked Subsystem

The Export to Unmasked Subsystem button writes the Interleaved Boost PFC circuit to a new model with no mask, alongside a parameter file that reproduces every mask value. Use it to inspect or edit the circuit beyond what the mask exposes.

File written to the current folderContents
InterleavedBoostPFC_exported_<timestamp>.slxThe unmasked circuit. Its PreLoadFcn runs the parameter file.
InterleavedBoostPFC_exported_<timestamp>_params.mAssigns the structure InterleavedBoostPFC in the base workspace. Every block parameter of the exported model references a field of this structure.
Note: The export keeps the variant subsystems, so the exported model still holds every device choice and still honors the choice the mask had when you exported it.

Plant Test Harness

The Interleaved Boost PFC block has an open-loop test harness, InterleavedBoostPFCTestHarnessPlant.slx, in the test folder of InterleavedBoostPFCPlant. The harness holds this block, the PWM generator blocks that drive its gate port, the input source, the load and a scope on the measurement bus. It carries no controller: constant reference blocks set the operating point, so the harness exercises the power stage on its own.

BlockRole in the harness
Interleaved Boost PFCThis block, taken from ConverterPlantLibrary, at the mask values the shipped converter model uses.
Interleaved PWM GeneratorThe two-leg modulator of the Interleaved Boost PFC Controller, masked so that it reads interleavedDesign and interleavedController directly. It emits one gate per leg from one duty input, with the second leg carrier shifted by half a switching period.
Duty ReferenceConstant duty 1 - sqrt(2)*interleavedDesign.nomInputVoltage/interleavedDesign.outputVoltage, the boost duty at the peak of the nominal line. Both legs take the same duty.
Vac, RloadAC voltage source of amplitude VacAmp at Fline, and the load resistance Rload_R, both from the defaults script.
Bus Selector, Leg Currents, ScopeVin [V], Iout [A] and Vout [V] off the measurement bus, with IL1 [A] and IL2 [A] on one axis so that the two legs can be compared.

Opening the harness runs InterleavedBoostPFCDefaultInputParameters through its PreLoadFcn, so every design and controller structure the generator masks read is in the base workspace before the first simulation. The solver is ode23t, as in the converter model the harness was taken from.

Note: The generator is set to Fixed-step (discrete), which is the mode the Interleaved Boost PFC Controller runs. Both legs then carry the same current.

The stop time is 0.1 s, five cycles of the 50 Hz line.
