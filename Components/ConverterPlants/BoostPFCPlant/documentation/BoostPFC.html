Description

The Boost PFC block models a single-phase power factor correction power stage: a full-bridge diode rectifier, a boost stage, a start-up pre-charge branch and the output filter capacitor. One gate signal drives the boost switch.

The circuit contains:

  • Diode rectifier bridge - four diodes, D1 to D4.
  • Boost stage - the boost inductor Lboost, the switch Q and the boost diode Db.
  • Pre-charge branch - the resistor Rpc in series with a diode, bridging the rectified node to the output.
  • Output filter - the capacitor Co with its series resistance.

Export to Unmasked Subsystem

The Export to Unmasked Subsystem button writes the Boost PFC circuit to a new model with no mask, alongside a parameter file that reproduces every mask value. Use it to inspect or edit the circuit beyond what the mask exposes.

File written to the current folderContents
BoostPFC_exported_<timestamp>.slxThe unmasked circuit. Its PreLoadFcn runs the parameter file.
BoostPFC_exported_<timestamp>_params.mAssigns the structure BoostPFC in the base workspace. Every block parameter of the exported model references a field of this structure.
Note: The export keeps the variant subsystems, so the exported model still holds every device choice and still honors the choice the mask had when you exported it.

Plant Test Harness

The Boost PFC block has an open-loop test harness, BoostPFCTestHarnessPlant.slx, in the test folder of BoostPFCPlant. The harness holds this block, the PWM generator blocks that drive its gate port, the input source, the load and a scope on the measurement bus. It carries no controller: constant reference blocks set the operating point, so the harness exercises the power stage on its own.

BlockRole in the harness
Boost PFCThis block, taken from ConverterPlantLibrary, at the mask values the shipped converter model uses.
Boost PWM GeneratorHalf Bridge PWM Generator from ConverterLibrary. Switching frequency from boostPFCDesign, gate levels from boostPFCController.
Duty ReferenceConstant duty 1 - sqrt(2)*boostPFCDesign.nomInputVoltage/boostPFCDesign.outputVoltage, the boost duty at the peak of the nominal line.
Boost Switch GateSelector taking element 1 of the generator's complementary pair, because the power stage has one boost switch.
Vac, RloadAC voltage source of amplitude VacAmp at Fline, and the load resistance Rload_R, both from the defaults script.
Bus Selector, ScopeVin [V], Iin [A], Iout [A] and Vout [V] off the measurement bus.

Opening the harness runs BoostPFCDefaultInputParameters through its PreLoadFcn, so every design and controller structure the generator masks read is in the base workspace before the first simulation. The solver is ode23t, as in the converter model the harness was taken from.

The stop time is 0.05 s, two and a half cycles of the 50 Hz line.
