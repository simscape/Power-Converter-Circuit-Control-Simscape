Description

The Non-Isolated DC-DC block models one of six DC-DC power stages, selected by the modelOption parameter. The choices are Buck, Synchronous Buck, Boost, Synchronous Boost, Buck-Boost and Synchronous Buck-Boost. The gate port is one element wide for the three non-synchronous topologies and two elements wide for the three synchronous ones.

Each topology contains a main switch, a freewheeling or rectifying element, the energy storage inductor and the output filter capacitor. The non-synchronous topologies use a diode as the freewheeling element; the synchronous topologies replace it with a second MOSFET. The inductor block is named Lout in the buck topologies, Lin in the boost topologies and Lstore in the buck-boost topologies.

Circuit Topologies

Note: The two buck-boost topologies invert the output. The Vout+ terminal shares a node with the input and Vout- carries the negative output voltage.

Export to Unmasked Subsystem

The Export to Unmasked Subsystem button writes the Non-Isolated DC-DC circuit to a new model with no mask, alongside a parameter file that reproduces every mask value. Use it to inspect or edit the circuit beyond what the mask exposes.

File written to the current folderContents
NonIsolatedDCDC_exported_<timestamp>.slxThe unmasked circuit. Its PreLoadFcn runs the parameter file.
NonIsolatedDCDC_exported_<timestamp>_params.mAssigns the structure NonIsolatedDCDC in the base workspace. Every block parameter of the exported model references a field of this structure.
Note: The export keeps the variant subsystems, so the exported model still holds every device choice and still honors the choice the mask had when you exported it.

Plant Test Harness

The Non-Isolated DC-DC block has an open-loop test harness, NonIsolatedDCDCTestHarnessPlant.slx, in the test folder of NonIsolatedDCDCPlant. The harness holds this block, the PWM generator blocks that drive its gate port, the input source, the load and a scope on the measurement bus. It carries no controller: constant reference blocks set the operating point, so the harness exercises the power stage on its own.

BlockRole in the harness
Non-Isolated DCDCThis block, taken from ConverterPlantLibrary, at the mask values the shipped converter model uses.
Half Bridge PWM GeneratorHalf Bridge PWM Generator from ConverterLibrary. Switching frequency, dead time and gate levels from nonIsolatedDCDCController. Its complementary pair reaches the G port unchanged, because the generator emits the high-side gate first.
Duty ReferenceConstant duty nonIsolatedDCDCDesign.nominalDuty.
Vin, RloadDC voltage source Vin_dc and load resistance Rload_R, both from the defaults script.
Bus Selector1, Mux, Mux1, ScopeIin [A] with IL [A] on one axis, Vin [V] with Vout [V] on the next, and Iout [A] on the third.

Opening the harness runs NonIsolatedDCDCDefaultInputParameters through its PreLoadFcn, so every design and controller structure the generator masks read is in the base workspace before the first simulation. The solver is ode23t, as in the converter model the harness was taken from.

The stop time is 20 ms.
