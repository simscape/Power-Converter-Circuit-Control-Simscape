Description

The CLLC Converter block models a bidirectional CLLC resonant power stage: two full bridges coupled by a transformer, with a resonant capacitor and a leakage inductance on each side of it. Two independent four-element gate vectors drive the two bridges.

The circuit contains:

  • Primary bridge - four switches, A1, A2, B1 and B2.
  • Primary resonant elements - the capacitor C1 with its series resistance, and the leakage inductance Llk1.
  • Transformer, with the magnetizing inductance Lm and the turns N1 and N2.
  • Secondary resonant elements - the capacitor C2 with its series resistance, and the leakage inductance Llk2.
  • Secondary bridge - four switches, A1, A2, B1 and B2. Power flow is bidirectional.
  • Output filter - the capacitor Co with its series resistance.

Gate Vector Order

Both vectors use the same element order, and it is the same order in both model options.

ElementDrivesRole
Gpri(1), Gsec(1)MOSFETA1Leg A high side.
Gpri(2), Gsec(2)MOSFETA2Leg A low side.
Gpri(3), Gsec(3)MOSFETB1Leg B high side.
Gpri(4), Gsec(4)MOSFETB2Leg B low side.
Note: Elements 1 and 4 form one diagonal of the bridge and elements 2 and 3 form the other. The CLLC PWM Generator block produces both vectors in this order.

Export to Unmasked Subsystem

The Export to Unmasked Subsystem button writes the CLLC Converter circuit to a new model with no mask, alongside a parameter file that reproduces every mask value. Use it to inspect or edit the circuit beyond what the mask exposes.

File written to the current folderContents
CLLC_exported_<timestamp>.slxThe unmasked circuit. Its PreLoadFcn runs the parameter file.
CLLC_exported_<timestamp>_params.mAssigns the structure CLLC in the base workspace. Every block parameter of the exported model references a field of this structure.
Note: The export keeps the variant subsystems, so the exported model still holds every device choice and still honors the choice the mask had when you exported it.

Plant Test Harness

The CLLC Converter block has an open-loop test harness, CLLCTestHarnessPlant.slx, in the test folder of CLLCConverterPlant. The harness holds this block, the PWM generator blocks that drive its gate port, the input source, the load and a scope on the measurement bus. It carries no controller: constant reference blocks set the operating point, so the harness exercises the power stage on its own.

BlockRole in the harness
CLLC Converter Power CircuitThis block, taken from ConverterPlantLibrary, at the mask values the shipped converter model uses.
CLLC PWM GeneratorCLLC PWM Generator from ConverterLibrary, which drives both Gpri and Gsec. Every mask value is the value the CLLC Converter Controller sets on its own copy of this generator.
Frequency ReferenceConstant 1. The generator takes its commanded frequency per unit of Fbase, which is CLLCDesign.resonantFreq, so 1 runs the bridge at the resonant frequency.
Secondary Current Select, Secondary Current DelayResonantTank.Is [A] off the measurement bus, delayed one major step by a Memory block. The generator times the synchronous rectifier from that current, so the delay keeps the gate path out of an algebraic loop.
Vin, RloadDC voltage source inputVoltage and the load resistance the converter model ships with.
Measurement, ScopeThe measurement subsystem of the converter model, unchanged, which forms the tank, input and output traces from the measurement bus.

Opening the harness runs CLLCConverterDefaultInputParameters through its PreLoadFcn, so every design and controller structure the generator masks read is in the base workspace before the first simulation. The solver is ode23t, as in the converter model the harness was taken from.

The stop time is 10 ms.
