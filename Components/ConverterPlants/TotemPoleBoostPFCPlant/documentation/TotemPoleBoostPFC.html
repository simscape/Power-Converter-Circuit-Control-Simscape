Description

The Totem-Pole Boost PFC block models a bridgeless power factor correction power stage: two half-bridge legs across the DC bus with the boost inductor in the AC line, and no input diode bridge. A four-element gate vector drives both legs.

The circuit contains:

  • Fast leg - Q1 and Q2, switching at the converter switching frequency.
  • Slow leg - two devices commutating at the line frequency. Diodes, MOSFETs or thyristors, selected by slowLegDeviceOption.
  • Boost inductor Lboost in the AC line, with its series resistance.
  • Output filter - the capacitor Co with its series resistance.

The block icon follows the slow leg selection: TotemPoleDiodeIcon.svg, TotemPoleMOSFETIcon.svg or TotemPoleThyristorIcon.svg.

Export to Unmasked Subsystem

The Export to Unmasked Subsystem button writes the Totem-Pole Boost PFC circuit to a new model with no mask, alongside a parameter file that reproduces every mask value. Use it to inspect or edit the circuit beyond what the mask exposes.

File written to the current folderContents
TotemPoleBoostPFC_exported_<timestamp>.slxThe unmasked circuit. Its PreLoadFcn runs the parameter file.
TotemPoleBoostPFC_exported_<timestamp>_params.mAssigns the structure TotemPoleBoostPFC in the base workspace. Every block parameter of the exported model references a field of this structure.
Note: The export keeps the variant subsystems, so the exported model still holds every device choice and still honors the choice the mask had when you exported it.

Plant Test Harness

The Totem-Pole Boost PFC block has an open-loop test harness, TotemPoleBoostPFCTestHarnessPlant.slx, in the test folder of TotemPoleBoostPFCPlant. The harness holds this block, the PWM generator blocks that drive its gate port, the input source, the load and a scope on the measurement bus. It carries no controller: constant reference blocks set the operating point, so the harness exercises the power stage on its own.

BlockRole in the harness
Totem-Pole Boost PFCThis block, taken from ConverterPlantLibrary, with slowLegDeviceOption set to MOSFET and both MOSFET dropdowns set to MOSFET (Ideal, Switching) with Thermal, so that all four positions are MOSFETs.
Fast Leg PWM GeneratorHalf Bridge PWM Generator from ConverterLibrary. Switching frequency from totemPoleDesign, dead time totemPoleController.fastLegDeadTime.
Slow Leg PWM GeneratorComplementary PWM Generator from ConverterLibrary, turn-on delay totemPoleController.slowLegTurnOnDelay and logic threshold 0, so the slow leg follows the sign of the line voltage.
Line Voltage Select, Line Voltage DelayVin [V] off the measurement bus, delayed one major step by a Memory block. The slow leg gate is derived from a plant measurement, so the delay is what keeps the gate path out of an algebraic loop.
Duty Scale, Duty Offset, Duty LimitFeedforward fast-leg duty 1 - |Vin|/totemPoleDesign.outputVoltage, saturated to totemPoleController.dutyMin and dutyMax.
Fast Leg Gate Order, Slow Leg Gate OrderSelectors placing the commanded duty on the fast-leg low-side switch and the line polarity on the slow-leg low-side switch, which are the active devices for a positive line half cycle.
Positive Half Gates, Negative Half Gates, Line PolarityThe four gates in the order the G port takes them, and the Switch that exchanges the two fast-leg elements on the negative line half cycle, where the two fast-leg switches exchange roles.
Vac, RloadAC voltage source of amplitude VacAmp at Fline, and the load resistance Rload_R, both from the defaults script.
Bus Selector, ScopeVin [V], IL [A], Iout [A] and Vout [V] off the measurement bus.

Opening the harness runs TotemPoleBoostPFCDefaultInputParameters through its PreLoadFcn, so every design and controller structure the generator masks read is in the base workspace before the first simulation. The solver is ode23t, as in the converter model the harness was taken from.

Note: The fast-leg duty is a feedforward term rather than a constant. The power stage is bridgeless and synchronous, so nothing in it blocks reverse inductor current, and a duty held at its peak-line value leaves the inductor with a negative average voltage near the line zero crossing. The feedforward duty holds the average inductor voltage near zero across the whole line cycle. It shapes no current: the inductor current peak is above the design value, which is what an open-loop excitation gives.

The stop time is 2/totemPoleDesign.lineFrequency.value, two cycles of the 50 Hz line.
