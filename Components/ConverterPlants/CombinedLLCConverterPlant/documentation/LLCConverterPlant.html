The block icon is a circuit schematic that changes with the LLC Converter model (llcConverterModel: half-bridge or full-bridge primary) and the rectifier topology (rectifierOption: centre-tap or full bridge). Each shipped icon is shown once under its combination heading in Circuit Topologies below.

Description

The LLC Converter Plant block models the power stage of an LLC series-resonant converter. The primary inverter is selectable (half-bridge or full-bridge) and the secondary rectifier is selectable (centre-tap or full-bridge diode rectifier), giving the family of circuit configurations shown in Circuit Topologies. The converter operates by driving the resonant tank at variable frequency to regulate the output voltage under varying load conditions.

The block comprises three functional sections:

  • Primary Inverter — a half-bridge (S1, S2) or full-bridge (S1–S4, legs a and b) that generates a square-wave AC voltage from the DC input bus, selected by llcConverterModel.
  • Resonant Tank (Cr, Lr, Lm, T1) — series resonant capacitor and inductor with a parallel magnetizing inductance and isolation transformer. The tank shapes the current waveform to enable soft switching (ZVS) of the primary switches.
  • Secondary Rectifier — a centre-tap rectifier (D1, D2) or a full-bridge rectifier (D1–D4), selected by rectifierOption, feeding the output filter capacitor Co.

Circuit Topologies

The block selects the primary inverter with llcConverterModel and the secondary rectifier with rectifierOption. All configurations share the same resonant tank (series capacitor Cr, series inductance Lr, magnetizing inductance Lm) and isolation transformer T1, and an output filter capacitor Co. The schematic the block displays for each combination is its own shipped mask icon:

Note: The Simplified Half-Bridge model always uses the centre-tap rectifier (it draws the Half-Bridge + Centre-Tap icon regardless of rectifierOption). The two Detailed models honor both rectifier choices, giving the four distinct icons below.

Half-Bridge primary + Centre-Tap rectifier

Half-bridge inverter (S1, S2) driving the resonant tank into a centre-tapped secondary with two rectifier diodes (D1, D2). This is also the icon drawn for the Simplified Half-Bridge model.

Half-Bridge primary + Full-Bridge rectifier

Half-bridge inverter with a four-diode full-bridge secondary rectifier (D1–D4).

Full-Bridge primary + Centre-Tap rectifier

Full-bridge inverter (S1–S4, legs a and b) driving a centre-tapped secondary with two rectifier diodes (D1, D2).

Full-Bridge primary + Full-Bridge rectifier

Full-bridge inverter with a four-diode full-bridge secondary rectifier (D1–D4).

Internal Structure

Inside the mask the power stage is organized as two cascaded subsystems — LLC Primary Inverter and Resonant Tank → Rectifier — whose measurement signals are gathered by a Bus Creator into the meas output. This left-to-right decomposition mirrors the power flow shown in the circuit topologies above.

LLC Primary Inverter and Resonant Tank

Wraps two mutually exclusive implementations: an LLC Simplified Model (a flat, HDL-generatable half-bridge) selected by the Simplified Half-Bridge model option, and an LLC Detailed Model selected by the two Detailed model options. The Detailed model contains the primary inverter (half- or full-bridge, per llcConverterModel) with the two switch-fidelity choices from Model Variants, together with the resonant tank (series capacitor Cr, series inductance Lr as an explicit inductor or transformer leakage per seriesInductorOption, magnetizing inductance Lm, and the isolation transformer). It emits the inverter sensors (Vin, Iin) and tank sensors (Ip, Vp, Is, Vs).

Rectifier

Contains the secondary rectifier — a centre-tap pair (D1, D2) or a four-diode full bridge (D1–D4) per rectifierOption, each with an Ideal-Diode or Tabulated-Diode fidelity choice — plus the output filter capacitor Co and the output sensors (Iout, IL, Vout, Vac).

Equations

The LLC resonant converter is characterized by the following key relationships:

Resonant Frequency

fr = 1 / (2π √(Lr · Cr))

where Lr = Llk1 (primary leakage inductance used as resonant inductor).

Characteristic Impedance

Z0 = √(Lr / Cr)

Inductance Ratio

k = Lm / Lr

Quality Factor

Q = Z0 / Rac

where Rac = (8/π²) · n² · Rload is the reflected AC-equivalent load resistance.

DC Voltage Gain (at resonance)

M = Vout / (Vin / (2n)) = 1   (at fsw = fr)

where n = N1/N2 is the transformer turns ratio.

Normalized Switching Frequency

fn = fsw / fr

Export to Unmasked Subsystem

The block's mask dialog includes an Export to Unmasked Subsystem button that produces a standalone, fully editable copy of the block as currently configured. Use it when you want to customize the actual circuit (add a snubber, change a sensor, retune a device the mask does not expose) rather than only configure it through the mask dropdowns.

Clicking the button writes two files to the current MATLAB folder:

  • LLC_exported_<timestamp>.slx — a standalone model whose top level is a single subsystem carrying the block icon. Inside is the circuit with no parameter mask: every Simscape block is open and editable, and the ports are exposed for wiring into your own test harness.
  • LLC_exported_<timestamp>_params.m — a script that assigns every parameter into a base-workspace struct (for example LLC.Lr = 3e-5; % H). The exported model's PreLoadFcn runs this file automatically, so the struct is populated as soon as the model opens. Parameter formulas are preserved (each mask variable is retargeted to its struct field), so the parametric relationships stay editable through this file.

Key properties of the exported model:

  • Zero links back to the converter library — you fully own the copy; later library changes never silently alter it. Product-library links (fl_lib, ee_lib, nesl_utility, …) are kept, since those are the Simscape component definitions.
  • Layout matches the library block - block positions and wiring are preserved, so the exported circuit is visually identical to the source block.
  • No Solver Configuration inside — the solver belongs in your harness. The exported subsystem exposes open ports and compiles once connected to your model's solver.
Note: The export keeps the variant subsystems, so the exported model still holds every device choice and still honors the choice the mask had when you exported it.

Plant Test Harness

The block has an open-loop test harness, LLCTestHarnessFullBridge.slx, in the test folder of CombinedLLCConverterPlant. The harness holds this block, the PWM generator that drives its G port, the input source, the load and a scope on the measurement bus. It carries no controller: a constant reference sets the operating point, so the harness exercises the power stage on its own.

BlockRole in the harness
LLC Converter Power CircuitThis block, configured Detailed Full-Bridge with a Full Bridge rectifier, the transformer leakage inductance as the series inductance, thermal switching MOSFETs on the primary and tabulated diodes on the secondary.
LLC PWM GeneratorLLC PWM Generator from ConverterLibrary, which produces the four-element gate vector directly. Base frequency, per-unit frequency limits and dead time from llcCompensator, pulse width 0.5, gate levels 15 V and 0 V.
Fref (pu)Constant 1. The generator takes its commanded frequency per unit of Fbase, which is llcCompensator.resonantFrequency, so 1 runs the bridge at the resonant frequency.
Vin, RloadDC voltage source at 385 V and a 20.48 Ohm load, the rated operating point of the shipped design.
RefA 100 kOhm resistance across the output, which gives the output node a path to the electrical reference before the rectifier conducts.
Measurement, ScopeFour traces off the measurement bus, Vac, Iac, Idc and Vout, one per scope axis.

Opening the harness runs LLCConverterDefaultInputParameters through its PreLoadFcn unless LLCDesign is already in the base workspace, so the values the generator mask reads are there before the first simulation. The solver is ode23t and the stop time is 10 ms.

Note: Every other plant block in this library has a harness of its own, built to the same pattern and named <Converter>TestHarnessPlant.slx. See the Plant Test Harness section of DAB Converter, CLLC Converter, Boost PFC, Interleaved Boost PFC, Totem-Pole Boost PFC or Non-Isolated DC-DC.
