selectConverterParts

Rank Simscape™ catalog parts against converter device rating

PowerConverterUtilities / PartSelection

Syntax

partTable = selectConverterParts(deviceRating)partTable = selectConverterParts(deviceRating,Name=Value)

Description

partTable = selectConverterParts(deviceRating) returns the installed Simscape catalog parts that meet both the voltage rating and the current rating of each device role in deviceRating. For each role, the table lists up to five parts, the part with the smallest total margin first, and the function prints the ranked list.

partTable = selectConverterParts(deviceRating,Name=Value) specifies options using one or more name-value arguments. For example, set NumberOfParts to 10 to list 10 parts per device role.

Examples

List Catalog Parts for Boost PFC Converter

Rate the boost PFC converter devices, then list the five best-fitting catalog parts for each device role.

BoostPFCDefaultInputParameters
deviceRating = selectBoostPFCDeviceRating(boostPFCSpec,Design=boostPFCDesign);
partTable = selectConverterParts(deviceRating,NumberOfParts=5);

Input Arguments

deviceRating - Device rating

Device rating, specified as a table with one row per rating. The table must contain the columns Rating, Unit, MetadataField, DeviceRole and ModelingEntityId. Each device role has one voltage rating row and one current rating row. Rating is the required value, Unit is its voltage or current unit, MetadataField is the catalog metadata field that the function compares against, and ModelingEntityId is the Simscape modeling entity of the catalog.

Name-Value Arguments

NumberOfParts - Number of parts per device role

Number of parts to return for each device role, specified as a positive integer scalar. Default: 5

Display - Option to print ranked list

Option to print the ranked list of parts for each device role in the Command Window, specified as a numeric or logical 1 (true) or 0 (false). Default: true

Output Arguments

partTable - Ranked catalog parts

Ranked catalog parts, returned as a table with one row per part. Within each device role, the rows are in order of smallest total margin first. The table contains the columns DeviceRole, Rank, Manufacturer, PartNumber, VoltageRating, CurrentRating, VoltageMarginPercent, CurrentMarginPercent, TotalMarginPercent, CollectionId and PartId. VoltageRating and CurrentRating are in the units of deviceRating.

Tips

  • The ranking measures how closely each part fits the rating, not its loss. To choose between ranks, compare the on-state resistance or forward voltage of the listed parts.
  • When no part collection is installed for a device role, or no installed part meets its rating, the function warns and omits that role from partTable.
