applyConverterPart

Apply catalog parts to converter plant in model

Syntax

appliedSummary = applyConverterPart(modelName,PartTable=partTable)appliedSummary = applyConverterPart(modelName,PartNumber=partNumber)

Description

appliedSummary = applyConverterPart(modelName,PartTable=partTable) applies the rank 1 part of each device role in partTable to the converter plant block in the model modelName. The function finds the plant block at the top level of the model and loads the model if it is not loaded. The model is not saved unless you set SaveModel to true.

appliedSummary = applyConverterPart(modelName,PartNumber=partNumber) applies the catalog part with part number partNumber instead of a part from a ranked table. To identify the part and its position when more than one device role uses the same catalog, also set Manufacturer and DeviceRole.

Examples

Apply Selected Parts to Boost PFC Converter Model

Rate the boost PFC converter devices, list the catalog parts that meet the ratings, then apply the rank 1 boost MOSFET and the rank 2 boost diode to the model and save it.

BoostPFCDefaultInputParameters
deviceRating = selectBoostPFCDeviceRating(boostPFCSpec,Design=boostPFCDesign);
partTable = selectConverterParts(deviceRating,NumberOfParts=5);
appliedSummary = applyConverterPart("BoostPFCConverter",PartTable=partTable, ...
    DeviceRole=["BoostMOSFET" "BoostDiode"],Rank=[1 2],SaveModel=true);

Input Arguments

modelName - Model name

Name of the model that contains the converter plant block, specified as a string scalar or character vector. You can specify the model name or its filename.

Name-Value Arguments

PartTable - Ranked catalog parts

Ranked catalog parts to apply from, specified as the table that the selectConverterParts function returns. Specify either PartTable or PartNumber, not both. Default: empty table

Rank - Rank of part to apply

Rank of the part to apply from PartTable, specified as a positive integer scalar or a row vector of positive integers. A scalar applies the same rank to every device role. A vector specifies one rank for each device role in DeviceRole. Default: 1

DeviceRole - Device roles to apply

Device roles to apply a part to, specified as a string array. When DeviceRole is empty, the function applies a part to every device role in PartTable. Default: string.empty(1,0)

Manufacturer - Catalog manufacturer

Manufacturer of the catalog part to apply, specified as a string scalar. Use Manufacturer together with PartNumber. Default: ""

PartNumber - Catalog part number

Part number of the catalog part to apply, specified as a string scalar. Specify either PartNumber or PartTable, not both. Default: ""

ConverterKey - Converter registry key

Converter registry key of the plant, specified as a string scalar. When ConverterKey is empty, the function detects the key from the plant block. Default: ""

PlantBlock - Plant block

Converter plant block to apply the parts to, specified as a string scalar that contains the full block path or the block name relative to the model. When PlantBlock is empty, the function finds the plant block at the top level of the model. Default: ""

DeriveIdealFromCurve - Option to fit ideal device values from I-V table

Option to fit the ideal device values that the part does not provide from the current-voltage table of the part, specified as a numeric or logical 1 (true) or 0 (false). Default: true

SaveModel - Option to save model

Option to save the model after the parts are applied, specified as a numeric or logical 1 (true) or 0 (false). When SaveModel is false, the model stays loaded and modified but unsaved. Default: false

Display - Option to print applied parts

Option to print the applied parts in the Command Window, specified as a numeric or logical 1 (true) or 0 (false). Default: true

Output Arguments

appliedSummary - Summary of applied parts

Summary of the applied parts, returned as a structure with the fields modelName, plantBlockPath, converterKey, modelSaved and roles. modelSaved is true when the function saved the model. roles is a structure array with one element per device role, as returned by the applyPartToDeviceRole function.

Tips

  • By default, the function does not save the model. To keep the applied parts, set SaveModel to true or save the model with the save_system function.
