converterRegistry

Settings of each converter for the analysis and part-selection functions

Syntax

entry = converterRegistry(converterKey)keys = converterRegistry()

Description

entry = converterRegistry(converterKey) returns the settings of the converter converterKey: the plant block, its device options, the operating-point blocks, the logged signals and the device roles for part selection. The analysis and part-selection functions read these settings, so one set of functions serves every converter.

keys = converterRegistry() returns the keys of the registered converters.

Examples

List the Registered Converters and Read One Entry

List the converter keys, then read the plant block name, the main workflow script and the device roles for part selection of the boost PFC converter.

keys = converterRegistry()
entry = converterRegistry("BoostPFC");
plantBlock = entry.plantSubsystem
mainScript = entry.mainScript
deviceRoles = [entry.parts.role]

The example displays this output.

Input Arguments

converterKey - Converter key

Key of a registered converter, specified as a string scalar or character vector, for example "BoostPFC".

Output Arguments

entry - Converter settings

Settings of the converter, returned as a structure. For the fields, see Entry Fields.

keys - Registered converter keys

Keys of the registered converters, returned as a string array.

Entry Fields

Each entry is a structure with these fields.

FieldDescription
keyConverter key, the name of the entry.
displayNameConverter name.
plantSubsystemName of the plant block at the top level of the model.
plantMaskTypeMask type of the plant block.
idealFidelityPlant mask settings that select the ideal devices, for the waveform and harmonic runs.
lossFidelityPlant mask settings that select the thermal and tabulated devices, for the loss run.
simTempParamsPlant mask parameters that set the device simulation temperature.
operatingPointOperating-point quantities, each with the block and the parameter it sets.
loadIdentifierName of the load block.
simlogVarName of the Simscape log in the simulation output.
logsoutVarName of the signal log in the simulation output.
ivPanelsLogged signals of each waveform axes, in display order. Optional.
ivPanelTitlesTitle of each waveform axes. Optional.
harmonicSignalsAC signals for the harmonic analysis. Optional.
partsDevice roles for part selection: the device blocks, the rating metadata and the ideal-value map. Optional.
directionalTrue for a bidirectional converter.
mainScriptName of the main workflow script.
inputParamScriptName of the default input parameters script.

Add a Converter

To make a new converter work with the analysis and part-selection functions:

  1. Build the converter model with the plant block at its top level, its controller, and the blocks the operating point sets, for example Vref, Vin and Rload.
  2. In converterRegistry.m, add a structure with the fields in Entry Fields to the buildRegistry function, then add it to the registry as r.<Key>.
  3. Log the signals that ivPanels and harmonicSignals name, and set the Simscape log and signal log names that simlogVar and logsoutVar name.
  4. Check the entry: converterRegistry("<Key>") returns it, and getConverterWaveforms and getConverterPowerLoss run on the model.
